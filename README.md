CryptoTaxEdge provides a digital-asset tax classification API that transforms on-chain transaction data into tax-ready categories and treatments. It offers an AI-driven classification engine with confidence scores and reasoning, supporting over 100 blockchains and thousands of protocol rules. The service is available via a REST API and an MCP server, with free tier limits and paid plans for higher volume. Documentation, pricing, and a public OpenAPI spec are hosted on the company site.

**Areas:** Company · Finance · Tax · Cryptocurrency · Accounting
